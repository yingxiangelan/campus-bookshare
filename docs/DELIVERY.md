# 校园二手书交易平台 - 项目说明

## 项目概述

本项目是一个完整的校园二手书交易平台Demo，基于微信小程序和Spring Boot开发，实现了从用户登录、书籍浏览、发布交易到消息沟通的完整闭环。

## 使用指南

### 快速开始（3步）

1. **配置数据库**
```bash
mysql -u root -p < database/init.sql
```

2. **启动后端**
```bash
cd backend
mvn spring-boot:run
```

3. **启动小程序**
- 用微信开发者工具打开 miniprogram 目录
- 编译运行

详细步骤请查看 `docs/STARTUP_GUIDE.md`
